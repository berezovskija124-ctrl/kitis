Расписание

Парсер обходит сервер 94.72.18.202:8083: списки групп, преподавателей и аудиторий, «Неделю» каждой группы, «Итоги» и все журналы занятий. Прошлые недели собраны из журналов, неделя со страницы «Неделя» показана как текущая или следующая — по сегодняшней дате.

Обновление

На GitHub данные обновляет задание GitHub Actions каждые 2 часа (пн–сб). Вручную — командой node parser/update.mjs или скриптом parser/browser-update.js в консоли браузера.

Остальное

Звонки, специальности, памятка абитуриента 2026, должности преподавателей, новости и контакты — с kitis.ru. Контактов преподавателей на kitis.ru нет, поэтому их на сайте тоже нет.
