# Новый сайт расписания КИТиС — учебный проект

Эскиз сайта расписания колледжа КИТиС для компьютера и телефона. Расписание, группы, преподаватели, аудитории, звонки и итоги всегда на виду. Остальные разделы kitis.ru собраны во вкладке «Меню».

> Это учебный проект, а не официальный сайт КИТиС. Формы входа и регистрации показаны для наглядности: данные никуда не отправляются.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Стартовая страница со ссылками на все экраны и QR-кодом для телефона |
| `desktop.html` | Версия для компьютера: расписание, группы, преподаватели, аудитории, звонки, итоги, «Меню» |
| `phone.html` | Версия для телефона: нижняя панель, вкладки «Пары / Звонки / Итоги», шторки |
| `home.html` | Меню → Главная колледжа |
| `abitur.html` | Меню → Абитуриентам |
| `student.html` | Меню → Кабинет студента |
| `teacher.html` | Меню → Кабинет преподавателя |
| `login.html`, `register.html` | Вход и регистрация |
| `sitemap.html` | Новая структура сайта: что на виду, а что в «Меню» |
| `structure.html` | Блочная структура страницы расписания |
| `dc-runtime.js` | Небольшой скрипт, который оживляет страницы (вкладки, таймер, поиск). Без него страницы не работают |

Сайт статический: ему не нужны сервер и сборка. Из интернета подгружаются только шрифты (Google Fonts) и скрипт QR-кода на стартовой странице (cdnjs).

## Как посмотреть у себя

Распакуйте архив и откройте `index.html` двойным щелчком. Всё работает прямо с диска. QR-код появится только после публикации сайта.

## Как выложить на GitHub Pages

### Через сайт GitHub (без программ)

1. Войдите на [github.com](https://github.com). Нажмите «+» в правом верхнем углу и выберите **New repository**.
2. Название — например, `kitis-raspisanie`. Видимость — **Public** (на бесплатном аккаунте Pages работает только с публичными репозиториями). Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
4. Откройте распакованную папку `kitis-raspisanie`, выделите **все файлы внутри неё** и перетащите в окно браузера. Перетаскивайте именно файлы, а не саму папку: `index.html` должен лежать в корне репозитория.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source:* **Deploy from a branch**, *Branch:* **main** и папку **/ (root)**. Нажмите **Save**.
7. Через 1–2 минуты сверху на той же странице появится ссылка вида `https://ваш-логин.github.io/kitis-raspisanie/`. Её и отправьте преподавателю.

### Через командную строку

```bash
cd kitis-raspisanie
git init
git add .
git commit -m "Эскиз сайта расписания КИТиС"
git branch -M main
git remote add origin https://github.com/ваш-логин/kitis-raspisanie.git
git push -u origin main
```

Затем включите Pages, как в шаге 6.

### Как обновить сайт

Загрузите изменённые файлы тем же способом (**Add file → Upload files**). Новые файлы заменят старые с теми же именами. Через минуту-две сайт обновится.
