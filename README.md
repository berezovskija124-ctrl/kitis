# Новый сайт расписания КИТиС — учебный проект

Сайт расписания колледжа КИТиС для компьютера и телефона. Расписание, группы, преподаватели, аудитории, звонки и итоги всегда на виду. Остальные разделы kitis.ru собраны во вкладке «Меню».

Пары всех 60 групп, 77 преподавателей и 46 аудиторий берутся с сервера расписания колледжа [94.72.18.202:8083](http://94.72.18.202:8083).

> Это учебный проект, а не официальный сайт КИТиС. Формы входа и регистрации показаны для наглядности: данные никуда не отправляются.

## Откуда берётся расписание

На сервере колледжа работает программа «Экспресс-расписание». Парсер обходит её страницы:

| Страница сервера | Что из неё берём |
|---|---|
| `cg.htm`, `cp.htm`, `ca.htm` | списки групп, преподавателей и аудиторий |
| `cgN.htm` — «Неделя» группы | актуальное расписание группы на опубликованную неделю |
| `vgN.htm` — «Итоги» группы | выполнение нагрузки: всего, по плану, проведено, осталось, процент |
| `jN.htm` — «Журнал занятий» | каждая проведённая пара: дата, номер пары, группа, подгруппа, преподаватель, аудитория |

На сайте недели собираются так:

1. **Прошлые недели** — из итогов, то есть из журналов занятий.
2. **Текущая неделя** — из актуального расписания группы («Неделя»). Если «Неделя» на сервере уже переключилась на следующую, текущая неделя берётся из журналов.
3. **Следующая неделя** — из «Недели», если её даты уже стоят на следующую неделю. На кнопке «Следующая неделя» тогда появляется отметка «опубликована».

Какая неделя текущая, сайт определяет по сегодняшней дате в Калининграде. Таймер до конца пары считается по расписанию звонков с kitis.ru. Время 7-й пары на kitis.ru не указано, поэтому у таких пар написано «время не указано».

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Стартовая страница: ссылки на все экраны, QR-код для телефона, демо «во время пары» |
| `desktop.html` | Версия для компьютера |
| `phone.html` | Версия для телефона |
| `home.html`, `abitur.html`, `student.html`, `teacher.html` | Разделы из «Меню» |
| `login.html`, `register.html` | Вход и регистрация |
| `sitemap.html`, `structure.html` | Новая структура сайта и блочная схема страницы |
| `data/kitis-data.js` | Данные с сервера расписания (перезаписывается парсером) |
| `kitis-model.js` | Логика недель, таймера и поиска пар по группе, преподавателю, аудитории |
| `dc-runtime.js` | Скрипт, который оживляет страницы (вкладки, таймер, поиск) |
| `parser/kitis-parser.js` | Парсер сервера расписания |
| `parser/update.mjs` | Обновление данных из командной строки (Node.js 18+) |
| `parser/browser-update.js` | Обновление данных из консоли браузера, без установки программ |
| `.github/workflows/update-schedule.yml` | Автообновление на GitHub каждые 2 часа (пн–сб) |

Сайт статический: ему не нужны сервер и сборка. Из интернета подгружаются только шрифты (Google Fonts) и скрипт QR-кода на стартовой странице (cdnjs).

## Как посмотреть у себя

Распакуйте архив и откройте `index.html` двойным щелчком. Всё работает прямо с диска.

Сайт показывает настоящее время. Вечером или в воскресенье пар нет, поэтому вместо таймера будет «Следующая пара». Чтобы увидеть, как сайт выглядит во время пары, добавьте к адресу время. Например: `desktop.html?now=2026-11-12T10:30` — четверг, 12 ноября, 10:30, у ИСр24-1 идёт 2 пара. Готовые ссылки есть на стартовой странице.

## Как выложить на GitHub Pages

1. Войдите на [github.com](https://github.com). Нажмите «+» в правом верхнем углу и выберите **New repository**.
2. Название — например, `kitis-raspisanie`. Видимость — **Public** (на бесплатном аккаунте Pages работает только с публичными репозиториями). Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
4. Откройте распакованную папку `kitis-raspisanie`, выделите **всё её содержимое** (файлы и папки `data`, `parser`, `.github`) и перетащите в окно браузера. `index.html` должен оказаться в корне репозитория.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source:* **Deploy from a branch**, *Branch:* **main** и папку **/ (root)**. Нажмите **Save**.
7. Через 1–2 минуты сверху на той же странице появится ссылка вида `https://ваш-логин.github.io/kitis-raspisanie/`. Её и отправьте преподавателю.

На macOS папка `.github` скрыта в Finder (нажмите Cmd + Shift + . , чтобы её увидеть). Если она не загрузилась, создайте файл вручную: **Add file → Create new file**, в имени напишите `.github/workflows/update-schedule.yml` и вставьте содержимое файла из архива.

### Через командную строку

```bash
cd kitis-raspisanie
git init
git add .
git commit -m "Сайт расписания КИТиС"
git branch -M main
git remote add origin https://github.com/ваш-логин/kitis-raspisanie.git
git push -u origin main
```

Затем включите Pages, как в шаге 6.

## Как обновлять расписание

### Автоматически (GitHub Actions)

После загрузки на GitHub задание «Обновление расписания» запускается каждые 2 часа с 05:17 до 19:17 по Калининграду, с понедельника по субботу. Если на сервере что-то поменялось, задание записывает новый `data/kitis-data.js`, и сайт обновляется сам.

- Запустить вручную: вкладка **Actions** → «Обновление расписания» → **Run workflow**.
- Если задание падает с ошибкой подключения, значит серверы GitHub не могут достучаться до сервера колледжа (он может быть закрыт для зарубежных адресов). Тогда обновляйте одним из способов ниже.
- GitHub отключает задания по расписанию, если в репозитории 60 дней не было изменений. Включить обратно можно во вкладке **Actions**.

### С компьютера (Node.js 18+)

```bash
node parser/update.mjs
```

Скрипт скачает страницы сервера (около 900 страниц, 1–2 минуты) и перезапишет `data/kitis-data.js`. Если расписание не изменилось, файл останется прежним. Затем загрузите `data/kitis-data.js` в репозиторий: **Add file → Upload files** в папке `data`.

### Из браузера, без установки программ

1. Откройте http://94.72.18.202:8083 в браузере.
2. Нажмите F12 и перейдите на вкладку «Консоль» (Console).
3. Вставьте весь текст файла `parser/browser-update.js` и нажмите Enter. Если браузер просит, сначала введите `allow pasting`.
4. Через 1–2 минуты скачается `kitis-data.js`. Загрузите его в папку `data` репозитория, заменив старый.
